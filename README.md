# 待辦事項 App

使用 React 初次完成的待辦事項清單，由於新手剛觸碰，基本上都是跟著網路教學影片完成的，除了有一些額外功能，是請 Claude 出題讓我在此 App 上自己新增一些功能與 UI。

---

## 主要功用

- 新增：透過輸入項目，點選加入或是按下 Enter，可以新增該項目。
- 刪除：透過點選垃圾桶圖示，可以刪除該項目。
- 編輯：可以對在項目清單中的項目進行項目的編輯，修改指定項目的標題。
- 標記：透過點選該項目字的本身，可以標記為**已完成**，也可再次點擊恢復為**未完成**。**已完成**會以加上刪除線與該項目顏色變淡來顯示。
- 一鍵清除：透過一鍵清除的按鈕可以刪除所有標記為**已完成**的項目。

---

## 執行

```bash
npm install
npm run dev
```
